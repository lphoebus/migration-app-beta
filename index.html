          About This App

          Migration Exploration App (Beta)

          This application is currently in development to help visualize flow from origin to destination and vice versa. The current example focuses on migration between states and counties, allowing you to interact with the data and explore patterns of inflow and outflow across the country.

          Data Source: Latest IRS Migration Data (2022–2023)
