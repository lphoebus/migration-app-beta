# Migration Explorer (Beta)

Migration Explorer is an interactive web map for exploring migration patterns across the United States. It helps users examine inflow, outflow, net migration, and contributor patterns at both the state and county level.

## What You Can Do

- Switch between state and county views
- Choose different analysis years
- View a migration snapshot for a selected geography
- Explore inbound and outbound flow patterns
- Review top source and destination locations
- See top flow routes for a selected place
- Highlight contributing places above a chosen threshold
- Compare migration metrics with a swipe view
- Apply different map styling modes for inflow, outflow, net migration, and rates

## Main Views

### Summary
Select a state or county to view a quick overview of inflow, outflow, net migration, top origins, top destinations, and the number of people who did not migrate.

### Flow Analysis
Explore directional migration patterns for a selected geography, adjust the minimum migrant threshold, and review the strongest visible routes.

### Contributor Analysis
Highlight the places that contribute most strongly to inflow or outflow based on a selected threshold.

### Swipe Compare
Compare two migration views side by side using different years or metrics.

## Data Source

This project uses IRS migration data.

Source: https://www.irs.gov/statistics/soi-tax-stats-migration-data
